# Week 05 – Matplotlib

## Overview

In Week 05, I learned how to use **Matplotlib** to visualize data in Python.

I practiced creating different types of charts and learned how to combine **Pandas DataFrames with Matplotlib** for data visualization.

## Topics Covered

During this week, I learned:

* Introduction to Matplotlib
* Line charts using `plt.plot()`
* Bar charts using `plt.bar()`
* Scatter plots using `plt.scatter()`
* Adding chart titles with `plt.title()`
* Adding axis labels with `plt.xlabel()` and `plt.ylabel()`
* Adding grids with `plt.grid()`
* Changing figure size with `plt.figure(figsize=...)`
* Adding legends with `plt.legend()`
* Displaying values on charts with `plt.text()`
* Improving layout with `plt.tight_layout()`
* Saving charts with `plt.savefig()`
* Using Pandas DataFrames with Matplotlib

## Project: Bridge Data Visualization

As a practical project, I created a small **Bridge Data Visualization** project using Pandas and Matplotlib.

The dataset contains information about five bridges, including:

* Bridge name
* Bridge length
* Maximum vibration

### Dataset

| Bridge   | Length (m) | Maximum Vibration |
| -------- | ---------: | ----------------: |
| Bridge 1 |        100 |               2.1 |
| Bridge 2 |        150 |               3.5 |
| Bridge 3 |        130 |               2.8 |
| Bridge 4 |        200 |               5.2 |
| Bridge 5 |        170 |               4.1 |

### Visualizations

I created three charts:

1. **Bridge Length – Line Chart**

   * Shows the length of each bridge.

2. **Maximum Vibration – Bar Chart**

   * Compares the maximum vibration values of the bridges.

3. **Bridge Length vs Maximum Vibration – Scatter Plot**

   * Shows the relationship between bridge length and maximum vibration.

The scatter plot suggests a positive relationship in this small dataset: longer bridges tend to have higher maximum vibration values.
