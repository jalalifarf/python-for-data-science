# Bridge Information System

A simple command-line application written in Python for managing bridge information using CSV files.

## Features

- Add a new bridge
- Show all bridges
- Search for a bridge
- Update bridge information
- Delete a bridge

## File Structure

```
bridge_information_system/
│
├── main.py
├── bridge_functions.py
├── file_manager.py
├── bridges.csv
└── README.md
```

## Skills Used

- Python Functions
- Modules
- CSV File Handling
- Exception Handling
- Loops
- User Input Validation

## Future Improvements
