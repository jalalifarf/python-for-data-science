## Project

Completed the **Bridge Data Analysis & Visualization V2** project.

The project uses a small bridge dataset containing:

- Bridge name
- Bridge length
- Construction year
- Material
- Maximum vibration

The program performs the following tasks:

- Displays bridge length comparisons
- Displays maximum vibration comparisons
- Visualizes the relationship between bridge length and maximum vibration
- Finds the longest bridge and its length
- Finds the bridge with the highest maximum vibration and its value
- Displays multiple visualizations in a single figure using subplots
- Adds annotations to the charts

## Visualizations

The project includes three main visualizations:

1. **Bridge Length Comparison**
   - A bar chart comparing the lengths of the bridges.

2. **Maximum Vibration Comparison**
   - A bar chart comparing the maximum vibration values.

3. **Bridge Length vs Maximum Vibration**
   - A scatter plot showing the relationship between bridge length and maximum vibration.

The project also combines the visualizations using Matplotlib subplots.

## Analysis

Based on this small dataset:

- Bridge 4 is the longest bridge, with a length of 200 meters.
- Bridge 4 also has the highest maximum vibration, with a value of 5.2.

The scatter plot suggests that longer bridges tend to have higher maximum vibration values in this dataset.

However, this observation is based on only five bridges and does not prove a causal relationship.
